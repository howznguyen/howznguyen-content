---

Someone on a forum pointed me at AutoPlay Media Studio. I did not know how to program, so I used what the tool allowed: dragged buttons, added images, assigned actions, and picked up a little script with each version.

The first thing I finished was Software All In One Necessary 1.0, a bundle of the drivers and tools people needed after reinstalling Windows. I posted it, read the replies, and made version 2, then 3. Nobody had explained feedback loops to me; I simply had users.

By version 3 the bundle was 439 MB, with Vietnamese and English interfaces, software sorted A to Z, a progress bar, and font handling for machines that rendered text wrong. I listed what did not work yet in the same post. I still like that habit.
