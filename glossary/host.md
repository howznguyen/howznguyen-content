# vi

Host là máy vật lý hoặc hệ thống nền cung cấp CPU, RAM, storage và network cho các môi trường ảo chạy bên trên. Trong series này, chiếc Dell OptiPlex 3010 chạy Proxmox là host.

Tìm hiểu thêm: [Red Hat - Basic concepts of virtualization](https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/10/html/configuring_and_managing_linux_virtual_machines/basic-concepts-of-virtualization-in-rhel).

# en

A host is the physical machine or underlying system that provides CPU, memory, storage, and networking to virtual environments running on top of it. In this series, the Dell OptiPlex 3010 running Proxmox is the host.

Learn more: [Red Hat - Basic concepts of virtualization](https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/10/html/configuring_and_managing_linux_virtual_machines/basic-concepts-of-virtualization-in-rhel).
