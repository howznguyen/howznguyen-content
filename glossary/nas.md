# vi

NAS, viết tắt của Network Attached Storage, là thiết bị hoặc máy chủ lưu trữ được kết nối vào mạng để nhiều thiết bị có thể truy cập và chia sẻ file. NAS thường có hệ điều hành riêng và được quản lý tập trung.

Tìm hiểu thêm: [IBM - What is network attached storage?](https://www.ibm.com/think/topics/network-attached-storage).

# en

NAS, short for Network Attached Storage, is a storage device or server connected to a network so multiple devices can access and share files. A NAS commonly has its own operating system and centralized management.

Learn more: [IBM - What is network attached storage?](https://www.ibm.com/think/topics/network-attached-storage).
