# vi

Virtualization, hay ảo hóa, là công nghệ chia tài nguyên của một máy vật lý thành nhiều môi trường tách biệt. Nhờ đó một chiếc PC có thể chạy nhiều máy ảo hoặc hệ thống riêng cùng lúc.

Tìm hiểu thêm: [Red Hat - What is virtualization?](https://www.redhat.com/en/topics/virtualization/what-is-virtualization).

# en

Virtualization divides the resources of one physical machine into multiple isolated environments. This allows a single PC to run several virtual machines or separate systems at the same time.

Learn more: [Red Hat - What is virtualization?](https://www.redhat.com/en/topics/virtualization/what-is-virtualization).
