# vi

Home hub là thiết bị trung tâm của Apple Home giúp chạy automation, chia sẻ quyền điều khiển và truy cập phụ kiện khi ở ngoài nhà. HomePod hoặc Apple TV tương thích có thể đảm nhận vai trò này.

Tìm hiểu thêm: [Apple Support - Set up a home hub](https://support.apple.com/en-gb/102557).

# en

A home hub is a central Apple Home device that enables automations, shared control, and access to accessories while away from home. A compatible HomePod or Apple TV can perform this role.

Learn more: [Apple Support - Set up a home hub](https://support.apple.com/en-gb/102557).
