# vi

Cloud là cách cung cấp tài nguyên hoặc dịch vụ máy tính qua mạng từ hạ tầng do một bên khác vận hành. Với Smart Home, thiết bị phụ thuộc cloud thường phải gửi lệnh tới máy chủ của hãng qua Internet trước khi nhận kết quả.

Tìm hiểu thêm: [NIST SP 800-145 - The NIST Definition of Cloud Computing](https://csrc.nist.gov/pubs/sp/800/145/final).

# en

Cloud computing delivers computing resources or services over a network from infrastructure operated by another party. In a smart home, a cloud-dependent device usually sends commands to the vendor's servers over the Internet before receiving a result.

Learn more: [NIST SP 800-145 - The NIST Definition of Cloud Computing](https://csrc.nist.gov/pubs/sp/800/145/final).
