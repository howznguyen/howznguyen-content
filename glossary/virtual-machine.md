# vi

Virtual machine, thường viết tắt là VM, là một máy tính được mô phỏng bằng phần mềm với CPU, RAM, storage, network và hệ điều hành riêng. Nhiều VM có thể chia sẻ cùng một host vật lý nhưng vẫn hoạt động như những máy tách biệt.

Tìm hiểu thêm: [Red Hat - What is virtualization?](https://www.redhat.com/en/topics/virtualization/what-is-virtualization).

# en

A virtual machine, commonly shortened to VM, is a software-defined computer with its own CPU, memory, storage, networking, and operating system. Multiple VMs can share one physical host while operating as separate machines.

Learn more: [Red Hat - What is virtualization?](https://www.redhat.com/en/topics/virtualization/what-is-virtualization).
