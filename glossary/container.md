# vi

Container là môi trường tách biệt để chạy ứng dụng hoặc một hệ thống nhỏ nhưng vẫn dùng chung kernel với host. Vì không cần một hệ điều hành đầy đủ cho từng môi trường, container thường nhẹ hơn máy ảo.

Tìm hiểu thêm: [Linux Containers - LXC Introduction](https://linuxcontainers.org/lxc/introduction/).

# en

A container is an isolated environment for running an application or a small system while sharing the host kernel. Because each environment does not need a complete operating system, containers are usually lighter than virtual machines.

Learn more: [Linux Containers - LXC Introduction](https://linuxcontainers.org/lxc/introduction/).
