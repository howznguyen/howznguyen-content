## Software

The apps I actually run, and what each one is holding down.

- **[OneNotch](https://macgrove.app/apps/onenotch)** - Clipboard history, screenshots and a calendar inside the MacBook notch. A new tool from a Vietnamese developer, picked up recently and worth keeping.
- **[Ghostty](https://macgrove.app/apps/ghostty)** - A GPU-native terminal that launches fast and stays native, and the one I open every day. Leaving AI out of it is what keeps it focused.
- **[Pen](https://macgrove.app/apps/pen)** - The design tool that replaced Figma: native on the Mac, with agents working on the same canvas and an MCP link straight into the coding side.
- **[ego lite](https://macgrove.app/apps/ego-lite)** - A Chromium browser I share with coding agents. They browse in their own Space with my real logins, so the automation runs while I keep my tabs.

The rest of what I run, and everything I would recommend, is in [macgrove Top picks](https://macgrove.app/top-picks), each one opened and checked by hand before it went in.

## Resources

Web UIs, courses, and the other things worth keeping within reach.

### Web UI

- **[Arc UI](https://uiarc.dev)** - Animated shadcn components and blocks for Next.js: 140 components, 83 blocks, installed through the shadcn CLI.
- **[Untitled UI](https://www.untitledui.com)** - A Figma UI kit and a matching React component library, both built on one design system and Tailwind throughout.
- **[affectUI](https://www.affectui.com)** - Hand-designed React components, blocks, illustrations and motion for AI products: each piece is one file I copy in and own, with no Tailwind or UI library needed.
