**Knowns is a local-first project memory layer for people and AI coding agents.**

It keeps the context that code cannot explain on its own: what the team is building, why a decision was made, which conventions still apply, what an agent should read, and what “done” means.

Instead of pasting the same background into every new coding session, you give the agent a path into the project knowledge it needs.

## The short version

Your repository already tells an agent **how the software works**.

Knowns keeps the things your team knows **about the work around that software**:

- **Tasks** describe what needs to happen and what counts as complete.
- **Docs** explain architecture, conventions, workflows, and product context.
- **Decisions** preserve why the team chose one direction over another.
- **Memory** keeps useful patterns, preferences, and lessons available across sessions.
- **References** connect those pieces instead of leaving them as isolated notes.

Everything stays close to the project, remains readable by people, and can be retrieved by coding agents through CLI or MCP.

<Callout type="info" title="The core idea">
  Knowns does not make the model smarter. It gives the model structured access
  to what the project already knows.
</Callout>

## From a cold session to a working loop

Without project memory, a new session often begins with copy-pasting architecture notes, repeating conventions, and explaining old decisions again.

With Knowns, the loop becomes:

1. **Capture** the task, context, and acceptance criteria.
2. **Link** the relevant docs, decisions, patterns, and past work.
3. **Retrieve** only the context the current task needs.
4. **Work and verify** against the same acceptance criteria.
5. **Remember** useful decisions and lessons for the next session.

The result is not “AI that knows everything.” It is an agent with a reliable way to search, follow references, and stop guessing.

A task can hold its description, acceptance criteria, implementation plan, priority, labels, references, and progress. The agent and the person reviewing its work read from the same definition of done.

## Get started

You can install Knowns with Homebrew, shell, PowerShell, npm, or try it directly with `npx`.

```bash
npx knowns@latest init

# Optional: open the local Web UI
knowns browser --open
```

Then connect the coding agent you already use. Knowns works as the project memory layer around that workflow; it does not replace your editor, Git, tests, or code review.

Full installation guides are available on [knowns.sh](https://knowns.sh), and the source code lives on [GitHub](https://github.com/knowns-dev/knowns).
