**Nookdeck turns an old phone or tablet into a control panel for your computer.** Nookdeck was previously called PhoneDesk. It is a small agent that runs on your Mac or Windows PC and serves a touch overlay to any browser on the same Wi-Fi. There is nothing to install on the phone, and no account or cloud service.

The project is early (0.x). macOS is the main target and Windows 10/11 is experimental. Builds are not signed with an Apple Developer ID or a Windows certificate, and the installers handle that.

## What you can do

- **Shortcuts.** Open apps (with their real icons) and URLs, send key combinations, type text, run shell commands and macros, and use media and volume keys.
- **Monitoring.** CPU, memory, network, load and uptime with selectable chart styles. Tapping CPU shows the process list.
- **AI coding.** Claude, Codex and Antigravity quotas with reset times, a choice of which windows to show, and local Claude Code and Codex sessions.
- **Claude Code from the couch.** With opt-in hooks, answer Allow or Deny permission prompts and Claude's multiple-choice questions on the phone. If no phone answers in time, Claude Code asks in the terminal as usual.
- **Everyday widgets.** Now Playing with artwork, six clock styles and world clocks, weather in °C or °F, a soundboard, and notifications.
- **Home Assistant (optional).** Lights with colour, colour temperature, scenes and effects. Climate, fans, covers, vacuums, locks and sensors.
- **Automation.** Webhooks that push values and notifications, and rules that react to activity on the computer. An MCP server lets an AI assistant arrange the layout for you.

## Make it yours

The layout is a fixed grid of square tiles, built in a drag-and-drop management page at `http://localhost:7420/manage/`. Grids such as 8x4, 8x3 and 5x3 are available, with four tile styles (Soft, Solid, Outline, iOS), any colour per tile, more than 5,000 icons, and English or Vietnamese.

## Works on small phones

A screen size picker above the preview lets you see the deck at iPhone 5s/SE, iPhone, Pro Max, Android, iPad or a custom size, so you know what an old phone will show. A warning appears when tiles get too small to tap.

## Install

You need a Mac (macOS 13 or later) or a Windows 10/11 PC, and a phone or tablet on the same Wi-Fi. On a Mac, run:

```sh
curl -fsSL https://nookdeck.app/scripts/install | bash
```

On Windows, run this in PowerShell:

```powershell
irm https://nookdeck.app/scripts/install.ps1 | iex
```

The installer prints a QR code, a phone address and a 6-digit PIN. Scan the code with the phone's camera, or type the address and PIN, then add the page to the home screen for a full-screen panel. Nookdeck starts by itself each time you sign in.

## Local only

Everything runs on your own computer and your own network. The management page is only reachable from the computer itself, and a phone has to be paired with a PIN. AI quotas are read-only: Nookdeck reads the sign-in Claude Code already stored without refreshing it, Codex's local session files and Antigravity's local server. The repository documents every outbound connection in its privacy notes.
