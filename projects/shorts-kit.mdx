**shorts-kit** turns a coding agent into a small studio for narrated vertical shorts: TikTok, YouTube Shorts and Reels.

You tell your agent "make a video about why the sky is blue". It works through the kit's skills one step at a time: facts first, then a storytelling flow, the script, the voice, the scenes, stills to check, the render, the cover and the caption. You review along the way and upload the file yourself. The kit never posts anything.

## Where it comes from

I ran a Vietnamese knowledge channel on TikTok with an agent doing almost all of the production. In two months it went from zero to 1,170 followers, and seven videos reached 24K to 122K views. Others got a few hundred.

Most rules in the kit were written right after a published video broke them. A video fails to reach For You, a cover gets misread at thumbnail size, a voice engine reads a phrase three times in a loop. Each rule keeps the reason it exists, so you can judge whether it applies to your channel. All of them are defaults you can change.

## What is in it

| Part | What it does |
| --- | --- |
| 9 `sk-*` skills | One per pipeline step, started by `sk-pipeline`. Work in Claude Code and any agent that reads `AGENTS.md` |
| `SOUL.md` | The channel rulebook: voice, sentence style, writing for TTS, safe zones, captions, audio, facts, covers. Each rule tagged `[measured]`, `[default]`, `[craft]` or `[hard]` |
| 20 storytelling flows | Three reasons, Trace back, Explain it, Reading a graph, Empty world with a late reveal, and more |
| Fact ledger | No sentence enters a script before its claim has a verified record. The linter enforces it |
| Storyboard | After the voice, every camera shot is planned (camera, what is on screen, text, transition) and approved before any scene code |
| Remotion library | Word-timed captions, kinetic type, a safe-zone overlay, camera moves, an illustrated world (sky, sea, moon, rain, people) |
| Maps and globe | Satellite imagery that stays sharp from country to street, Natural Earth coasts and borders, routes that draw on, a Vietnam map with the Hoàng Sa and Trường Sa archipelagos, a 3D globe with great-circle lines, and a pull-out from any scene to the globe |
| CC0 sound effects | Eight effects generated by the kit, plus a guide on when to use them and when not to |
| Scripts | TTS with word timestamps, lint, render, loudness normalisation, a platform-ready encode |
| Preview dashboard | `bun run preview`: progress per video, the script with the spoken word highlighted, the storyboard with frames from the render, the cover at profile-grid size, the caption ready to copy |

  encoding. On the original channel, the topic decided views more than anything
  else. Videos close to the audience got tens of thousands of views, and videos

## Install

You need [Bun](https://bun.sh) 1.3 or later, [ffmpeg](https://ffmpeg.org), and a coding agent (Claude Code, Codex, OpenCode). For the voice, the built-in macOS `say` works offline and free; [ElevenLabs](https://elevenlabs.io) sounds much better and needs an API key in `.env`.

```bash
brew install bun ffmpeg          # macOS; on Linux: the bun install script + apt install ffmpeg
git clone https://github.com/howznguyen/shorts-kit.git
cd shorts-kit
bun install
```

Check that everything works by building the example video, "Why is the sky blue?":

```bash
bun run tts example && bun run lint example
bun run render example && bun run cover example
bun run normalize example && bun run encode example
bun run preview                  # open http://127.0.0.1:7788
```

`out/example/example-upload.mp4` is the file you would upload.

## Make it yours

Open your agent in the repo and say:

> set up the kit for my channel

`sk-improve` asks about your niche, language, platform, voice, tone and video length, then edits `SOUL.md` and the numbers in `docs/soul/thresholds.json` to match, and logs every change. The rules are defaults: relax or delete any that your own numbers contradict.

## Make a video

Say "make a video about …". `sk-pipeline` walks the steps below and tells you where it is. Most of your work is approving, listening and looking.

| Step | The agent | You |
| --- | --- | --- |
| Facts | Sources every claim and records it in `docs/facts/` | Nothing, unless a fact is contested |
| Flow and brief | Picks a storytelling flow, writes `briefs/<id>.md`, checks image licences | Agree with the angle |
| Narration | Writes the script line by line, each line tied to a fact id; `bun run lint` checks style | Approve the script |
| Voice | `bun run tts <id>`: one read of the whole script, with word timestamps | Listen once, end to end |
| Storyboard | `bun run storyboard <id> --init`, then fills in every shot | Approve the shots in the preview's Storyboard tab |
| Scenes | Builds only approved shots in Remotion, renders stills and looks at them | Look at the stills |
| Render and hand-off | Render, cover, loudness, encode, caption and pinned comment with credits | Watch it once |
| Upload | Never | Upload by hand, set the cover, paste the pinned comment |
| After posting | `sk-improve` records what the numbers taught | Paste the stats |

## Maps and the globe

List the camera shots of a map video in `src/videos/<id>/map.json`, then:

```bash
bun run satellite <id>   # EOX Sentinel-2 imagery, one mosaic per zoom level (CC BY 4.0, credit on frame)
bun run geo <id>         # coastlines, borders and rivers from Natural Earth
bun run dev gallery      # browse every map, globe and illustrated component
```

Distances on frame are measured between real coordinates, not quoted, and long routes are drawn as great circles.
