**shorts-kit** turns a coding agent into a small studio for narrated vertical shorts: TikTok, YouTube Shorts and Reels.

You tell your agent "make a video about why the sky is blue". It works through the kit's skills one step at a time: facts first, then a storytelling flow, the script, the voice, the scenes, stills to check, the render, the cover and the caption. You review along the way and upload the file yourself. The kit never posts anything.

## Where it comes from

I ran a Vietnamese knowledge channel on TikTok with an agent doing almost all of the production. In two months it went from zero to 1,170 followers, and seven videos reached 24K to 122K views. Others got a few hundred.

Most rules in the kit were written right after a published video broke them. A video fails to reach For You, a cover gets misread at thumbnail size, a voice engine reads a phrase three times in a loop. Each rule keeps the reason it exists, so you can judge whether it applies to your channel. All of them are defaults you can change.

## What is in it

| Part | What it does |
| --- | --- |
| 9 `sk-*` skills | One per pipeline step, started by `sk-pipeline`. Work in Claude Code and any agent that reads `AGENTS.md` |
| `SOUL.md` | The channel rulebook: voice, sentence style, writing for TTS, safe zones, captions, audio, facts, covers. Each rule tagged `[measured]`, `[default]`, `[craft]` or `[hard]` |
| 20 storytelling flows | Three reasons, Trace back, Explain it, Reading a graph, Empty world with a late reveal, and more |
| Fact ledger | No sentence enters a script before its claim has a verified record. The linter enforces it |
| Remotion library | Word-timed captions, kinetic type, a safe-zone overlay, camera moves, and an illustrated world: sky, sea, moon, rain, people |
| CC0 sound effects | Eight effects generated by the kit, plus a guide on when to use them and when not to |
| Scripts | TTS with word timestamps, lint, render, loudness normalisation, a platform-ready encode |
| Preview dashboard | `bun run preview` shows every video's progress, the render, stills, the cover at profile-grid size, and the caption ready to copy |

<Callout type="info" title="The topic is still yours">
  The kit takes care of the craft: structure, facts, safe zones, loudness and
  encoding. On the original channel, the topic decided views more than anything
  else. Videos close to the audience got tens of thousands of views, and videos
  that drifted from the niche got a few hundred.
</Callout>

## Quick start

Bun, ffmpeg and a coding agent are required. On a Mac the example video runs offline with the built-in `say` voice.

```bash
git clone https://github.com/howznguyen/shorts-kit.git
cd shorts-kit
bun install
bun run tts example && bun run render example && bun run encode example
bun run preview
```

Then open your agent in the repo and say "set up the kit for my channel". `sk-improve` asks about your niche, language and voice, and adapts the rules. After that, "make a video about …" starts `sk-pipeline`.
